# Face detector fixtures

Photos from the COCO 2017 validation set (https://cocodataset.org), each under the
Creative Commons Attribution 2.0 licence (https://creativecommons.org/licenses/by/2.0/).
Converted to PNG (the Android unit tests read PNG only). Used only to test FaceDetector.kt against ml/faces.py; not part of the app.

- `two-faces.png`: COCO 885, Flickr http://farm4.staticflickr.com/3715/9639200419_ee41490b2a_z.jpg
- `four-faces.png`: COCO 13291, Flickr http://farm4.staticflickr.com/3394/3491087208_8efdfeb6d4_z.jpg
- `no-face.png`: COCO 7574, Flickr http://farm8.staticflickr.com/7054/6924897347_7266fd119c_z.jpg
